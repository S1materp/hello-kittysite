# Ветки 
## *переименование и переключение* 
 - ***git checkout -b branch_name***-создание новой ветки с именем бранч нейм и переключение на нее
 - ***git switch -c branch_namee***-создание новой ветки с именем бранч нейм и переключение на нее
 - ***git branch -d branch_name***-el- удаление ветки с именем гит бранч (если она была слита с дргуими ветками )
 - ***git branch -D branch_name*** - удаление ветки с именем branch_name, даже если она не была полностью слита с другими ветками
 -*** git branch -M new_branch_name*** переименовывает текущую ветку, если ветка с именем нью бранч уже сущ, она будет перезаписана а новыми данными без каких либо бополнительных запросов или подтверждений
 - ***git branch -m new_branch_name*** переименовывает и если имена одинаковые то будет сообщение об ошибке
  
  ## *слияние*
  + ***git merge*** используется для объединения изменений из одной ветки в другую. Обычно это делается для включения изменений из одной исхожной ветки в текущую вчетку целевую  
     **пример выполнения такого слияния:**
     1. git checkout main  (переключились с одной ветки на другугю)
     2. git merge feature_branch  (произвили слияние с другой веткой )
     3. Если гит обнаружит конфликты(еслди одна и таже часть файла была изменена в обеих ветках между которыми при этом не выплнялось слияние ) надо его разрешить вручную 
     4. после разрешения конфликта вызываем классический гит коммит дял фиксации слияния
